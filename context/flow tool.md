# MECMS: Equipment Calibration Workflow (Context for Development)

## 1. System States (สถานะเครื่องมือในระบบ)

- **รอสอบเทียบ** (Pending Calibration)
- **กำลังสอบเทียบ** (Calibrating)
- **รอดำเนินการ** (Pending Approval)
- **พร้อมใช้งาน** (Active / Ready)
- **ปิดใช้งาน** (Disabled / Out of Order)

## 2. Workflow & Logic (ลำดับการทำงานและเงื่อนไข)

### Phase 1: Initiation (เริ่มต้นการสอบเทียบ)

- **Trigger:** ถึงรอบกำหนดเวลาสอบเทียบ (Due Date)
- **Action:** ระบบปรับสถานะเครื่องมืออัตโนมัติเป็น `รอสอบเทียบ`

### Phase 2: External Inspection (ตรวจสอบสภาพภายนอก)

- **Trigger:** ช่างเทคนิคกดรับงานหรือเริ่มตรวจสภาพ
- **Action:** ระบบอัปเดตสถานะเป็น `กำลังสอบเทียบ`

**เงื่อนไขผลการตรวจสอบสภาพภายนอก:**
| ผลการตรวจ | สถานะถัดไป | การดำเนินการ |
| :--- | :--- | :--- |
| **ผ่าน (Pass)** | `กำลังสอบเทียบ` | ดำเนินการวัดค่าสอบเทียบต่อไป |
| **ไม่ผ่าน (Fail)** | `ปิดใช้งาน` | ส่งเข้ากระบวนการซ่อมบำรุง (จบ Flow การสอบเทียบ) |

### Phase 3: Calibration Measurement (บันทึกผลสอบเทียบ)

- **Trigger:** ช่างเทคนิคกรอกผลการวัดค่า (ผ่าน/ไม่ผ่าน) และกดส่งงานให้หัวหน้า
- **Action:** ระบบอัปเดตสถานะเป็น `รอดำเนินการ` เพื่อรอการตรวจสอบ

### Phase 4: Manager Approval (การตรวจสอบและอนุมัติจากหัวหน้า)

**เงื่อนไขการตัดสินใจของหัวหน้าแผนก:**
| ผลสอบเทียบจากช่าง | การตัดสินใจของหัวหน้า | สถานะเครื่องมือ | ผลลัพธ์เพิ่มเติมในระบบ |
| :--- | :--- | :--- | :--- |
| **ผ่าน (Pass)** | **อนุมัติ (Approve)** | `พร้อมใช้งาน` | ระบบออกใบ Cer 2 ใบ และบันทึกลงประวัติ |
| **ไม่ผ่าน (Fail)** | **อนุมัติ (Approve)** | `ปิดใช้งาน` | เครื่องมือตกสเปก บันทึกลงประวัติ |
| **ผ่าน (Pass)** | **ไม่อนุมัติ (Reject)** | `รอสอบเทียบ` | ตีกลับให้ช่างนำเครื่องไปสอบเทียบใหม่ |
| **ไม่ผ่าน (Fail)** | **ไม่อนุมัติ (Reject)** | `รอสอบเทียบ` | ตีกลับให้ช่างนำเครื่องไปสอบเทียบใหม่ |

## 3. Data Storage & Output (การจัดเก็บข้อมูลและแสดงผล)

- **History Logging:** ทุกรายการที่หัวหน้ากด "อนุมัติ" (Approve) จะถูกบันทึกลงฐานข้อมูลและแสดงใน "หน้าประวัติสอบเทียบ"
- **Document Generation:** สำหรับเคสที่สอบผ่านและได้รับการอนุมัติ ระบบจะแนบเอกสาร 2 ใบ (ใบรายงานผลตรวจสภาพภายนอก และ ใบรับรองผลสอบเทียบ) ไว้ในหน้าประวัติให้สามารถดาวน์โหลดหรือเรียกดูได้
