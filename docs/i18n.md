# Localization & i18n Convention

มาตรฐานการแปลภาษาและการใช้งานข้อความ (i18n - Internationalization) ในโปรเจกต์ ซึ่งรองรับทั้งภาษาไทย (Thai) และภาษาอังกฤษ (English)

---

## 1. กฎเหล็กสูงสุดในการพัฒนา (Absolute Rules)

- [ ] **ห้ามระบุข้อความแบบ Hardcoded:** ห้ามเขียนข้อความภาษาไทย หรือภาษาอังกฤษลงไปใน Component Template หรือ Script โดยตรง เช่น `label="ลบข้อมูล"` หรือ `message: 'Delete successful'`
- [ ] **ต้องผ่านระบบ i18n เสมอ:** ข้อความแสดงผลทั้งหมดต้องถูกอ้างอิงผ่านฟังก์ชัน `$t('key')` หรือเรียกใช้งานใน `setup` ด้วย `const { t } = useI18n()`
- [ ] **รักษาความสอดคล้องของคีย์:** คีย์ในแฟ้มสคริปต์ภาษาอังกฤษ (`en-US/index.json`) และภาษาไทย (`th/index.json`) จะต้องมีคีย์และโครงสร้างที่เหมือนกันทุกประการ

---

## 2. ตัวอย่างการกำหนดไฟล์ Locale

### 🇺🇸 ไฟล์ภาษาอังกฤษ: `src/i18n/en-US/index.json`
```json
{
  "common": {
    "save": "Save",
    "cancel": "Cancel",
    "delete": "Delete"
  },
  "equipment": {
    "title": "Equipment Management",
    "code": "Equipment Code",
    "status": "Calibration Status"
  }
}
```

### 🇹🇭 ไฟล์ภาษาไทย: `src/i18n/th/index.json`
```json
{
  "common": {
    "save": "บันทึก",
    "cancel": "ยกเลิก",
    "delete": "ลบ"
  },
  "equipment": {
    "title": "จัดการอุปกรณ์",
    "code": "รหัสอุปกรณ์",
    "status": "สถานะการสอบเทียบ"
  }
}
```

## 3. วิธีการนำไปใช้งานในโค้ด (Usage)

### 3.1 การใช้งานใน Vue Template
เรียกใช้ผ่านคีย์ย่อยโดยตรงผ่านตัวแปรตัวช่วยสากล `$t`:

```html
<template>
  <q-card>
    <q-card-section>
      <div class="text-h6">{{ $t('equipment.title') }}</div>
    </q-card-section>

    <q-card-actions align="right">
      <q-btn flat :label="$t('common.cancel')" color="primary" />
      <q-btn :label="$t('common.save')" color="primary" />
    </q-card-actions>
  </q-card>
</template>
```

### 3.2 การใช้งานใน setup Script
ดึงฟังก์ชัน `t` มาใช้งานร่วมกับ Composable `useI18n()`:

```html
<script setup lang="ts">
import { useI18n } from 'vue-i18n';
import { Notify } from 'quasar';

const { t } = useI18n();

function showSuccessAlert() {
  Notify.create({
    type: 'positive',
    // ใช้ฟังก์ชัน t ในการดึงข้อความจากไฟล์แปลภาษา
    message: t('common.save') + ' ' + t('common.success')
  });
}
</script>
```
